# Amazon-E-Commerce-Sales-Analytics-
##  Project Overview

Amazon E-Commerce Sales Analytics is an end-to-end Data Analytics project that transforms raw Amazon sales data into actionable business insights. The project follows the complete analytics lifecycle, beginning with raw datasets sourced from Kaggle, followed by data cleaning in Microsoft Excel, data analysis in Microsoft SQL Server, and interactive dashboard creation in Power BI.

By integrating multiple datasets, this project provides valuable insights into sales performance, product categories, regional revenue, pricing strategies, international sales, and overall business KPIs to support data-driven decision-making.

---

##  Problem Statement

The objective of this project is to analyze Amazon E-Commerce sales data to uncover meaningful business insights related to revenue, sales performance, regional trends, product demand, pricing, and international sales contribution. The project demonstrates how raw business data can be transformed into interactive dashboards for better decision-making.

---

##  Dataset Description

The project uses multiple Amazon E-Commerce datasets sourced from Kaggle. The raw datasets were cleaned and transformed in Microsoft Excel before being imported into Microsoft SQL Server for analysis and later connected to Power BI for visualization.

##  Project Workflow

##  Key Business Insights

- Total Revenue exceeded **94 Million**.
- Processed over **129K Orders**.
- Sold more than **141K Units**.
- International sales contributed approximately **17%** of total revenue.
- Maharashtra generated the highest revenue among all states.
- Kurta was the highest revenue-generating product category.
- Expedited shipping contributed the highest share of revenue.
- Monthly revenue showed significant fluctuations across the reporting period.
- Interactive dashboards enabled deeper analysis through dynamic filtering.
